KubeBank is starting in namespace {{ .Release.Namespace }}. It's a demo bank: every account and
euro is play money, so never enter real card or bank details.

{{- if and .Values.ingress.enabled .Values.ingress.host }}

Open it at:  http{{ if .Values.ingress.tls }}s{{ end }}://{{ .Values.ingress.host }}
{{- else if .Values.ingress.enabled }}

The Ingress matches any hostname, so it answers on your ingress controller's address.
Set ingress.host to give it a name, e.g. --set ingress.host=kubebank.<ingress-ip>.sslip.io
{{- end }}

To reach it without an Ingress:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-web 8080:8080
  then open http://localhost:8080

Check every service is healthy:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

Penny, the AI money coach, uses the Ollama at {{ .Values.ollama.url }}
(preferred model {{ .Values.ollama.model }}). If nothing answers there, the bank still works and
only Penny's replies fail; point ollama.url at your Ollama to fix that. On CPU-only clusters an
answer takes 1-3 minutes.
